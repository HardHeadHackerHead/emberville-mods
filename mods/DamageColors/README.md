Recolours the damage numbers on your own screen (`BepInEx\config\quadslab.emberville.damagecolors.cfg`,
`Colours / Damage`). Works with or without Ember Multiplayer. In a multiplayer session it's **client only**: only
you need it, and it never keeps you from joining a game whose players don't have it.

An example for mod makers (about 30 lines): `[MultiplayerMod(Requirement.ClientOnly)]` with a *soft* dependency on
Ember Multiplayer. See the API guide that comes with Ember Multiplayer (`docs/API.md`).
